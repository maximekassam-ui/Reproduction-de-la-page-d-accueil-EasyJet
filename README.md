# 🛫 Reproduction de la page d'accueil EasyJet

## 📖 Description

Ce projet a été réalisé dans le cadre de ma formation Développeur Web et Web Mobile.

L'objectif était de reproduire une version simplifiée de la page d'accueil du sitee EasyJet en utilisant uniquement HTML5 et CSS3. Ce projet m'a permis de mettre en pratique l'intégration d'une maquette complexe, la gestion de la mise en page ainsi que la création d'une interface responsive.

REMARQUE : Il s'agit d'une reproduction graphique. Les boutons et le formulaire ne sont pas fonctionnels.

## 🎯 Objectifs pédagogiques

- Reproduire fidèlement une interface existante.
- Structurer une page web avec un HTML sémantique.
- Maîtriser les techniques de mise en page en CSS.
- Concevoir une interface responsive adaptée aux différents écrans.
- Développer de bonnes pratiques d'intégration.

## ✨ Fonctionnalités

- Reproduction de la page d'accueil EasyJet.
- Barre de navigation.
- Bannière principale avec moteur de recherche de vols.
- Sections promotionnelles.
- Footer complet.
- Adaptation responsive pour différentes tailles d'écran.

## 🛠️ Technologies utilisées

- HTML5
- CSS3
- Flexbox
- Media Queries
